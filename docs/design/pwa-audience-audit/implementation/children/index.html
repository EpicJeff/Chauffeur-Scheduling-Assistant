Four child experiences, in the working PWA.

Version 2.499.213. These are captures of the served application using fictional schedule, routine and household fixtures. The controls below compare the approved direction with the working screens and detail sheets.

What changed, and what these captures verify

Sprout has a picture-led next step, a familiar driver and Today / My things / Family navigation. Explorer has a pickup card, focused checklist, progress and a personal week. Navigator uses compact priorities and a two-week personal Plan. Copilot has a restrained blue organizer, with the original drive scheduler available when the member is configured and permitted to drive.

All stages keep task completion, routine substeps, task photos, rewards, programs, lists, messages, music and critters. Server-delivered stage capabilities and permissions remain authoritative. The checks exercise routine completion and refresh, pickup details, own-member future dates, read-only routine previews, reward navigation, feature access, capability overrides, adult/child shell switching, light/dark themes and narrow layouts with doubled text.

The approved prototype’s illustrative read-aloud, new planning controls and simulated car reservations are not new product features in this release. These isolated tests do not send real family messages or exercise live music, notifications or location tracking.
