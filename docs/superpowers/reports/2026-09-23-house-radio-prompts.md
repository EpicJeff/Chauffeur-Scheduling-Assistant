# Working radio artwork: exact prompts

Built-in ImageGen, 2026-09-23. Day uses the existing music-day.png close-up as a continuity reference; night edits the generated day face. Original outputs preserved. Shipped assets: `chauffeur/static/house_hybrid/radio-face-day.png` and `radio-face-night.png`.

## Day

```text
Use case: stylized-concept. Input image is a continuity reference for a real functioning web radio in this living room. Create a new straight-on close-up camera view of the SAME walnut vintage radio on the SAME oak bookshelf. Landscape 3:2, 1536x1024. Camera perfectly centered and square to the front face: the face is planar and rectangular, horizontal/vertical edges aligned with the image, tiny top/side depth only. Photoreal walnut grain, aged brass, woven speaker cloth, physical contact shadows, oak shelf, books beside it. Daylight from the room windows. Cabinet occupies approximately x8%-92%, y14%-86% of the complete image, with softly rounded corners. Shelf below, books at far edges and a little oak backing above. Radio must fill the view.
Design this functional backplate WITH RESERVED SURFACES for live HTML controls, which will be added later. Upper left half of face has beautiful beige woven speaker cloth, x14%-48%, y22%-52%. Upper right has one large inset rectangular DARK AMBER GLASS DISPLAY, x53%-86%, y22%-46%, with a narrow aged brass bezel; completely blank unlit glass inside, no numbers, text or reflected lettering. The lower control row is smooth dark walnut: three flat circular recessed brass mounting plates centered at x22%, y68%; x45%, y68%; x75%, y68%. Each plate diameter approximately 11% of total image width. NO raised knobs on these plates: rotating knobs will be drawn as live elements. Keep all three circles front-on, round, evenly aligned. A small blank horizontal brass plaque between speaker and control row, around x20%-47% y55%-60%, will hold live output selection. Reserve clear flat wood directly above each circular mounting plate for small live labels. No other buttons, tuning dials or painted controls. No logos, text, interface mockups, split-screen or watermark. The display and the three mounting plates must read as real manufactured parts of a cohesive, beautiful vintage radio. These deliberately usable surfaces are essential.
```

## Night

```text
Use case: lighting-weather. Input is the EDIT TARGET, the functional front-on walnut radio backplate. Create its matching NIGHT lighting variant. Change only the illumination: warm bookshelf accent lighting, soft amber fireplace/lamp bounce, darker surrounding oak. Preserve precisely the same framing, resolution, cabinet silhouette, grille, blank display rectangle, brass display bezel, small blank nameplate and THREE FLAT BRASS MOUNTING PLATES. Every edge and circle must remain in exactly the same image coordinates so interactive controls align. Keep the glass BLANK and unlit, no generated controls or lettering. No added knobs, no additions/deletions. Comfortably visible, photoreal materials. One image, no collage.
```
