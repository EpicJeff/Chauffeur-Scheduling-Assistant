# Threads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the household's open loops — vendors, projects, correspondence — a tracked home that detects stalls, feeds the pulse, drafts mail, files replies, and hands the Mind a second verb.

**Architecture:** New `services/threads.py` owns lifecycle, stall detection and history. One new `threads` table. Stalls become findings on the existing rail; open threads add load to `services/vitals.py`; `mailer.py` and `email_ingest.py` provide correspondence in both directions; `services/web.py` provides research. Surfaced on a Threads page, the PWA House tab, and agent tools.

**Tech Stack:** Python (FastAPI + TinyDB-style storage), Alpine.js + precompiled Tailwind, scenario tests run by `tools/test.py`.

**Spec:** `docs/superpowers/specs/2026-08-27-threads-design.md` — read it before any task.

## Global Constraints

- Every task: bump `chauffeur/config.yaml` version, commit subject ending `(vX.Y.Z)`, push. Task 1 bumps MINOR (2.428.x → 2.429.0); later tasks bump PATCH. Never ask.
- Full sweep green before every code commit: from `chauffeur/` run `python tools/test.py` (never piped). Docs-only commits skip it.
- Commits from PowerShell: NO double quotes in `-m`. Use bash single quotes or `git commit -F`.
- Tests are scenario scripts: import `tests/harness.py`, define `scenario_*()` using its `check(cond, msg)`, run under `if __name__ == '__main__':`. Mirror `chauffeur/tests/test_vitals.py`.
- LLM always mocked in tests (replace the module attribute); zero live calls. Same for SMTP and IMAP.
- After ANY template class change: `python tools/build_tailwind.py`, commit regenerated stylesheets.
- No browser dialogs — `showGlobalAlert` / `promptConfirm` / `promptInput`.
- Every registered setting needs a real control on its page or `test_settings_registry` fails.
- Every new route must be classified in `services/auth.py` or `test_auth` fails.
- **The agent never sends mail unread.** Drafting and sending are separate acts, always.
- Storage convention: module-level table handle + accessors holding `db_lock`.

class Thread(BaseModel):
    """An open loop with somebody outside the family."""
    id: str = Field(default_factory=lambda: uuid.uuid4().hex)
    title: str

    kind: str = 'project'                   # vendor | project
