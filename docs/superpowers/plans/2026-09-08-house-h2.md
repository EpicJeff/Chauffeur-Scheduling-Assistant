# The Home H2 Implementation Plan — garage, parametric cars, curb bus, driveway presence

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The sealed garage becomes the house's second room: parametric cars built from the family's real car records (present only when their tracker says home, warning plaques when fuel/charge is low), a street along the yard's front with the school bus at the curb while it is actually out, and a `body_type` field with a picker in the car editor (the hand path).

**Architecture:** `house_room.state` grows `garage` and `curb` sections beside the delegated kitchen eight (same try/except-to-`_CALM` per section). house.js gains a third camera mode (`garage`), a rebuilt garage massing whose door meshes hide when inside (the dollhouse trick), a `buildCar(params)` template library, and state-driven car/bus meshes rebuilt only when the garage/curb payload changes. The lean-in for the garage zone is tip-only in H2 (no cars board tile exists; painted plaques carry the detail) — the overlay files are untouched.

**Tech Stack:** as H1. Exterior fidelity law: everything new is canvas-procedural + tier-gated (standing ruling 2026-09-08).

**Spec:** `docs/superpowers/specs/2026-09-08-house-design.md` · **H1 plan (idioms):** `docs/superpowers/plans/2026-09-08-house-h1.md`
