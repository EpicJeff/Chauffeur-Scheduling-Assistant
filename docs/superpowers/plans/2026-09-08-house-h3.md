# The Home H3 Implementation Plan — mudroom, living room, the kitchen slims

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two more rooms complete the U-shaped house: a mudroom (left-back, behind the garage) that takes the door signal plus honest backpacks, and a living room (right side) that takes the radio and the critter laptop plus a hearth. The kitchen slims to food + fridge + window + calendar, and the corkboard becomes a PANTRY whose shelf stock empties as the shopping list grows.

**Architecture:** house.js generalizes the camera into a ROOMS registry (`enterRoom(name)`, per-room POS/AT, optional hide-group) and routes zones by a ZONE_ROOM map — `chfKitchenFocus(zone)` enters the zone's OWN room first, so the overlay keeps working for door (hero card) and radio (music widget) in their new rooms. Zone KEYS never change (door/radio/pet/board) — state shapes, overlay wiring and fallback rows ride through untouched. `house_room.state` adds one small `mudroom` section (`bags` = active children — honest, roster-derived). All layout empirically verified by probe screenshots (H1/H2 idiom).

**Tech Stack / laws:** as H1+H2 (fidelity ruling, render-on-demand, frozen /kitchen, bump+commit+push per task — arc opens at **2.465.0**).

**Spec:** `docs/superpowers/specs/2026-09-08-house-design.md` · prior plans: h1/h2 in the same folder.
