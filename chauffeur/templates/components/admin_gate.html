{# The admin surface's identity (auth arc S4). The dashboard and config page have never had one. That was defensible when they sat behind HA ingress; it stopped being defensible the day the app was published to the internet, and it is why /pin/clear could not be gated earlier — there was no token for the page to present. Three states, and the first-run one is the reason this is a component rather than a login box: * **claimed + signed in** — invisible, just a fetch wrapper attaching the token to every admin call. * **claimed + not signed in** — email and password. * **not claimed** — first run. Only offered when the request came through HA ingress, because that is proof Home Assistant already authenticated whoever is looking. Set a password for yourself and you are in; no mail round trip to yourself. Included by both admin pages so the two cannot drift apart. #}
