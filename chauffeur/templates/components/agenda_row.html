{# ── The agenda's own event row, and the day/event/today surfaces it wears — pulled out of `family_calendar.html`'s hand-drawn agenda so a second consumer can be a container for multiple events without inventing a second panel language for it. The user's own framing, verbatim: "Each day is a container for multiple events. An outing is the same concept, so make it use the same builder and styling as the agenda." The Family Day card's outing container used to be exactly that claim, drawn twice — this file is the one drawing, shared. Self-contained on purpose: `family_calendar.html` is deliberately not downloaded on a board with no calendar card (its own file comment says so), so a consumer that only needs the row — the Family Day card, on a board that may or may not also carry a calendar tile — cannot depend on anything family_calendar.html defines. Its own escape/time helpers live here too, under their own names, rather than reaching across an include boundary for `_agEsc`/`fmtTime`. `window.agendaEventRow(ev, opts)` returns a DOM element, not a markup string, so a caller that wants a plain HTML string (Alpine's `x-html`, which is how the Family Day card's blocks — built declaratively, not imperatively — get one) takes `.outerHTML`, and a caller building the DOM by hand (the calendar's own agenda) can `appendChild` it directly, the same way `_renderAgenda` always has. ev: { title, start, end, allDay, extendedProps: { driverName, carName, carSwap, assistName, isErrand, isConflict, isUnassigned, tripSuppressed, rawColor } } — FullCalendar's own event shape, the one the calendar's `eventContent` and agenda both already speak. opts: { canceled, extraBadgeHtml, trailingHtml } — canceled reuses the row's own past/tripSuppressed opacity treatment (nearest agenda precedent) and adds a line-through title; extraBadgeHtml is appended into the same badge slot the driver/car/covered chips already occupy, which is how a caller with its own badge (the Family Day card's amber/done pill) sits inline with the agenda's rather than beside it. trailingHtml is a second, GENERIC seam one step further right — the last thing in the row's own title/badge line, after everything else — for a caller that needs to end the row with something that is not a badge (the Family Day card's expand caret: it used to sit OUTSIDE the row as a flex sibling, which shrank the row's own right edge whenever a caret was present and left rows ragged, so it moved inside, here, as a plain trailing slot rather than a caret-shaped opt — this builder still knows nothing about expansion). Unset by every other caller, so the calendar's own agenda row is byte-for-byte unchanged. #}
